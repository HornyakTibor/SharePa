# SharePa

Share the school run with parents you trust. SharePa reads a family's calendar, finds parents going to the same practice or lesson, and lets them offer or join rides.

**Live demo:** https://sharepa.tiborhornyak.hu (in progress)

A portfolio project by Tibor Hornyák: product design, design system and prototype, built into a working app with Claude Code.

## Stack
Next.js 15 · TypeScript · Tailwind CSS · Supabase (Postgres, Auth, Realtime) · Vercel

## Run locally
```bash
cp .env.example .env.local   # add the Supabase publishable key
npm install
npm run dev
```
